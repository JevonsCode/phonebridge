# PhoneBridge 服务恢复

用户已确认：电脑登录后自动启动和恢复服务，手机提供一键启动入口，沿用原配对。

## 行为

- Windows 当前用户登录后运行后台管理程序，自动启动 Hub；Hub 意外退出时自动恢复，保留地址、端口和配对身份，不重放手机操作。
- 手机保存过电脑且断连时显示“启动电脑服务”。按钮使用原配对身份请求电脑启动 Hub，成功后重连；不重新扫码，不自动恢复曾被用户暂停的连接，除非用户按了按钮。
- 电脑关闭、睡眠、断网或管理程序不可达时明确提示“无法联系电脑，请确认电脑已开机并连接同一网络”。此功能不承诺远程开机。
- 旧版直接启动 Hub 的方式继续可用；没有管理程序时，手机告知需要更新电脑端，不能假报启动成功。

## 结构和协议

- 常驻 Supervisor 持有原外部 HTTP/WS 端口。Hub 子进程只监听随机 loopback 端口；Supervisor 透明代理已有 /status、/rpc、/device 请求，旧手机/MCP 配置无需变化。
- Supervisor 的 POST /service/start 用原 Bearer 配对令牌认证，拒绝浏览器 Origin 请求和其他方法，不接受命令、路径、端口或 shell 参数。返回 200 {serviceRunning:true} 仅在 Hub 已准备好之后；重复请求合并成一次启动。
- 子进程仅由固定本地 worker 入口启动。启动失败采用有限退避，管理程序退出时关闭子进程；密码和手机内容不写日志。
- Windows 安装脚本保存当前用户的固定 IP/端口配置，创建可卸载的当前用户登录计划任务，无管理员运行、无新增公网监听、无自动防火墙修改。安装时沿用 DPAPI 配对文件。登录任务保持后台运行，并配置异常失败重启。
- Android 原生异步 HTTP 请求不阻塞界面，不发送令牌给重定向目标；HTTP/HTTPS 由保存的 WS/WSS 地址转换。请求成功后恢复已保存连接。

## 验证

- Node 集成测试验证未授权/错误方法被拒绝、重复启动合并、Hub 子进程退出后恢复、原状态/RPC/WS 兼容、关闭管理程序后子进程清理。
- Flutter 测试验证按钮仅在有配对且断连时显示、点击调用原生方法、错误显示；Android 编译验证异步接口。
- 本机启动管理程序并沿用原 192.168.31.159:8767；检查任务注册、保存身份未变化、强制退出 Hub 后自动恢复。安装 APK 到已授权手机，真机检查按钮和重连。登录自启不通过重启整台电脑验证，报告该边界。
