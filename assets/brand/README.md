# PhoneBridge identity

`phonebridge.png` is the single master logo, generated using the built-in image generation model on 2026-10-11. The transparent original is retained without painting or platform-specific redesigns.

Run `python scripts/export-brand.py` with Pillow installed to reproduce platform sizes. All website, Android, Windows and macOS outputs derive from this file. White backgrounds are applied only to platform icon tiles.

Generation prompt: One production-quality symbol-only PhoneBridge logo connecting an Android phone and a computer. Simple geometric blue (#1967D2), softly rounded interlocking forms with a bridge/connection; elegant, friendly, calm utility identity. Flat vector-like shapes, strong small-size silhouette, centered square transparent canvas. No text, gradients, shadows, mockups or variants.
